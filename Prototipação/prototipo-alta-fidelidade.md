# Protótipo de Alta Fidelidade

O protótipo do **ScrumMaromba** foi desenvolvido no Figma com base nos requisitos e diagramas definidos no projeto.

## Acesso

- [Abrir arquivo Figma Design](https://www.figma.com/design/81IJz4VClXRSzifefjseaS/ScrumMaromba?node-id=37-1024)
- [Executar protótipo mobile](https://www.figma.com/proto/81IJz4VClXRSzifefjseaS/ScrumMaromba?node-id=19-1015&starting-point-node-id=19%3A1015&scaling=scale-down)
- [Executar protótipo desktop](https://www.figma.com/proto/81IJz4VClXRSzifefjseaS/ScrumMaromba?node-id=19-898&starting-point-node-id=19%3A898&scaling=scale-down)

## Organização

O arquivo possui versões desktop e mobile organizadas nas seguintes seções:

1. **Fluxo de Navegação**
2. **Autenticação, Foco Muscular e Restrições**
3. **Recomendações e Detalhes dos Exercícios**
4. **Registro e Histórico**

Também está disponível uma biblioteca visual com componentes e estilos reutilizados nas interfaces.

O protótipo contempla os requisitos de usuário **RU01–RU08** e os requisitos funcionais **RF01–RF08**, além de representar aspectos de usabilidade, acessibilidade e responsividade definidos nos requisitos não funcionais.

## Referência Visual

O desenvolvimento visual utilizou como referência o template:

[Fitness Tracking Mobile App Template](https://www.figma.com/community/file/1025480996191985788/fitness-tracking-mobile-app-template)
