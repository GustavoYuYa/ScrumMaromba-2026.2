# Requisitos de Sistema

## ScrumMaromba

Este documento apresenta os requisitos de sistema do ScrumMaromba, divididos em requisitos funcionais e requisitos não funcionais.

## Requisitos Funcionais

| ID | Requisito | Descrição |
|---|---|---|
| RF01 | Autenticar usuário | O sistema deve permitir que o usuário realize autenticação para acessar as funcionalidades associadas à sua conta. |
| RF02 | Selecionar região muscular | O sistema deve permitir que o usuário informe a região muscular que deseja trabalhar. |
| RF03 | Informar restrições físicas | O sistema deve permitir que o usuário informe limitações ou restrições físicas relevantes para a seleção dos exercícios. |
| RF04 | Recomendar exercícios | O sistema deve recomendar exercícios considerando a região muscular selecionada e as restrições físicas informadas pelo usuário. |
| RF05 | Visualizar exercícios recomendados | O sistema deve apresentar ao usuário os exercícios resultantes da recomendação. |
| RF06 | Visualizar detalhes do exercício | O sistema deve permitir que o usuário visualize informações detalhadas sobre um exercício selecionado. |
| RF07 | Registrar exercício realizado | O sistema deve permitir que o usuário registre a realização de um exercício. |
| RF08 | Consultar histórico de exercícios | O sistema deve permitir que o usuário consulte os exercícios registrados anteriormente. |

## Requisitos Não Funcionais

| ID | Requisito | Descrição |
|---|---|---|
| RNF01 | Usabilidade | O sistema deve apresentar uma interface de fácil compreensão e navegação para o usuário. |
| RNF02 | Acessibilidade | A interface deve utilizar textos legíveis, contraste adequado e elementos visuais que não dependam exclusivamente de cores para transmitir informações. |
| RNF03 | Responsividade | A interface do sistema deve adaptar-se a diferentes tamanhos de tela. |
| RNF04 | Segurança | O sistema deve proteger o acesso às funcionalidades e informações associadas às contas dos usuários. |
| RNF05 | Privacidade | O sistema deve preservar a privacidade das informações fornecidas e registradas pelos usuários. |
| RNF06 | Desempenho | O sistema deve responder às interações do usuário em tempo adequado para utilização da aplicação. |
| RNF07 | Compatibilidade | O sistema deve funcionar nos principais navegadores web atuais. |
