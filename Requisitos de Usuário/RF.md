# Requisitos Funcionais

## RF01 — Autenticar usuário

**Descrição:**  
O sistema deve permitir que o usuário se autentique para registrar exercícios realizados e consultar seu histórico.

**Prioridade:** Alta

**Requisitos relacionados:**  
RF07, RF08, RNF04

---

## RF02 — Selecionar região muscular

**Descrição:**  
O sistema deve permitir que o usuário selecione a região muscular que deseja exercitar.

**Prioridade:** Alta

**Requisitos relacionados:**  
RF04, RNF01

---

## RF03 — Informar restrições físicas

**Descrição:**  
O sistema deve permitir que o usuário informe restrições físicas a serem consideradas na recomendação de exercícios.

**Prioridade:** Alta

**Requisitos relacionados:**  
RF04, RNF01

---

## RF04 — Recomendar exercícios

**Descrição:**  
O sistema deve recomendar exercícios considerando a região muscular selecionada e as restrições físicas informadas.

**Prioridade:** Alta

**Requisitos relacionados:**  
RF02, RF03, RF05, RNF05

---

## RF05 — Visualizar lista de exercícios

**Descrição:**  
O sistema deve exibir a lista de exercícios resultante da recomendação.

**Prioridade:** Alta

**Requisitos relacionados:**  
RF04, RF06, RNF05

---

## RF06 — Visualizar detalhes do exercício

**Descrição:**  
O sistema deve permitir que o usuário visualize os detalhes de um exercício selecionado.

**Prioridade:** Média

**Requisitos relacionados:**  
RF05, RF07

---

## RF07 — Registrar exercício realizado

**Descrição:**  
O sistema deve permitir que o usuário autenticado registre um exercício como realizado.

**Prioridade:** Alta

**Requisitos relacionados:**  
RF01, RF06, RF08, RNF04

---

## RF08 — Consultar histórico de exercícios

**Descrição:**  
O sistema deve permitir que o usuário autenticado consulte os exercícios registrados como realizados.

**Prioridade:** Média

**Requisitos relacionados:**  
RF01, RF07, RNF04, RNF05
