# Requisitos de Usuário

## ScrumMaromba

Este documento apresenta as principais necessidades dos usuários do ScrumMaromba.

| ID | Requisito | Descrição |
|---|---|---|
| RU01 | Autenticar-se no sistema | O usuário deseja autenticar-se para acessar as funcionalidades associadas à sua conta. |
| RU02 | Informar foco muscular | O usuário deseja informar a região muscular que pretende trabalhar. |
| RU03 | Informar restrições físicas | O usuário deseja informar limitações ou restrições físicas relevantes para a prática de exercícios. |
| RU04 | Receber sugestões de exercícios | O usuário deseja receber sugestões de exercícios compatíveis com o foco muscular e as restrições informadas. |
| RU05 | Visualizar exercícios sugeridos | O usuário deseja visualizar os exercícios recomendados pelo sistema. |
| RU06 | Consultar informações de um exercício | O usuário deseja visualizar informações sobre um exercício antes de realizá-lo. |
| RU07 | Registrar exercícios realizados | O usuário deseja registrar a realização de exercícios. |
| RU08 | Consultar histórico de exercícios | O usuário deseja consultar os exercícios realizados anteriormente. |
